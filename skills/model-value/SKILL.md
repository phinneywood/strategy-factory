# model-value

Start with the causal chain:

intervention -> behavior/process change -> operational outcome -> economic or strategic value

Challenge vague benefits such as "save time", "improve quality", or "increase adoption" until the downstream value is explicit.

For each material value driver capture:
- baseline
- affected population/volume
- expected change as a range
- mechanism
- value conversion
- confidence
- evidence or assumption
- measurement method and owner

Include:
- implementation cost
- ongoing operating cost
- coordination/change-management cost
- opportunity cost where material
- downside and displacement effects

Use ranges/scenarios rather than false precision. Separate observed inputs from assumptions.

End with a value hypothesis, leading indicators, lagging outcome measures, and the assumptions that dominate the result.
